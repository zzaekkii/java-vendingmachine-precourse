# java-vendingmachine

# 📌 요구사항 요약

반환되는 동전이 최소한이 되는 자판기 구현
<br/>

# 📝 구현할 기능 목록

### 자판기 보유 동전을 생성하는 기능

- [x] 자판기 보유금 입력 문구를 출력한다.
- [x] 보유금을 입력받는다.
    - [x] 10으로 나눠떨어지는 숫자인지 검증한다.
- [x] 자판기 보유금으로 동전을 무작위 생성한다.
- [x] 자판기가 보유한 동전 목록을 출력한다.

### 상품을 등록하는 기능

- [x] 상품 정보 입력 문구를 출력한다.
- [x] 상품 정보들을 입력받는다.
    - [x] `;`를 구분자로 추출한 뒤, 개별 상품 정보 형식 `[` `]` 이 맞는지 검증한다.
    - [x] 상품 가격이 100원 이상이고 10으로 나눠떨어지는지 검증한다.
    - [x] 상품명이 문자나 숫자로만 이뤄져있는지 검증한다.
- [x] 자판기에 상품들을 등록한다.

### 투입금을 입력받는 기능

- [x] 투입금 입력 문구를 출력한다.
- [x] 투입금을 입력받는다.
    - [x] 10으로 나눠떨어지는 숫자인지 검증한다.

### 상품 구입 기능

- [x] 현재 투입금 잔액을 출력한다.
- [x] 현재 자판기 상품 재고가 남아있는지 확인한다.
    - [x] 재고가 없다면 바로 잔돈을 반환한다.
- [x] 현재 투입금이 자판기 상품 중 최저 가격보다 적은지 확인한다.
    - [x] 적다면 바로 잔돈을 반환한다.
- [x] 구매할 상품명을 입력받는다.
    - [x] 존재하는 상품인지 확인한다 (재고 및 존재 여부)
    - [x] 구매하려는 상품 가격이 잔돈보다 높다면 에러 문구를 출력한다.
    - [x] 구매가능하다면, 투입금에서 상품 가격만큼 차감한다.

### 자판기 잔돈 반환 기능

- [x] 보유한 동전을 최소 개수로 사용해서 투입금 잔액만큼 만든다.
    - [x] 보유 동전이 잔액보다 많지만, 잔돈 거스름이 불가능하면 부족한대로 끝낸다. `ex. 500원 1개인데 100원을 반환해야하는 경우`
    - [x] 보유 동전이 잔액보다 적으면, 보유 동전을 모두 반환한다.
- [x] 반환한 잔돈 목록을 출력한다.

# 💡 스스로 판단한 규칙

- [x] 상품뿐만 아니라 자판기 보유금과 투입금도 10원으로 나눠떨어져야 한다.
- [x] 상품 가격은 0원보다 커야한다.
- [x] 고른 상품보다 잔액이 적으면 에러 메시지를 출력하고 다시 입력받는다.
- [x] 고른 상품의 재고가 없으면 에러 메시지를 출력하고 다시 입력받는다.
